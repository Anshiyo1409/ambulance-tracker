📍 Mobile GPS Troubleshooting

Why is GPS blocked on my phone?

Mobile browsers (Chrome / Safari) strictly require HTTPS or localhost for GPS. If you are opening a local IP like http://192.168.x.x:3000, follow these options:

Option 1 (Fastest): Use Simulation Mode

Tap "Simulate Movement" on your phone. It sends realistic live movement coordinates that update the laptop in real time without needing GPS permissions!

Option 2: Allow Insecure Origin in Mobile Chrome
  1. On mobile Chrome, navigate to chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Add your laptop's URL (e.g., http://192.168.1.15:3000).
  3. Select Enabled and tap Relaunch.
Option 3: Use Free Cloud Relay / HTTPS

Deploy to GitHub Pages, Netlify, or Vercel for instant free HTTPS on your phone!
